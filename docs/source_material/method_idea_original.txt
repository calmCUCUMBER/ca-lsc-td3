# 十一、液态神经网络不要用原始 LTC，我建议正式采用 CfC

\[

\]

> **Closed-form Continuous-time Neural Network**

LTC 本质上是连续时间动态网络，但需要数值 ODE 求解。CfC 是从 LTC 推导出的闭式连续时间结构，可以显式处理时间间隔，同时避免昂贵的数值 ODE solver。CfC 原始论文特别强调了连续时间、时序建模和计算效率。

这和 VTOL transition 是有内在匹配关系的。

因为你的转换不是：

\[

\rightarrow

\]

这么简单，而是：

\[
\boxed{

\rightarrow
\text{transition trend}
\rightarrow
a_t
}
\]

例如：

同样：

\[

一种情况可能是：

\[

\]

机翼升力正在快速建立；

另一种可能：

\[
\dot V_a<0
\]

正在遭遇阵风或减速。

瞬时状态类似，但未来应该采取的：

\[
\lambda
\]

不同。

液态网络正好用于捕捉这种连续动态历史。

Critic 数量从：

# 十四、为什么 Safety Critic 也必须是 Twin Critic

这是一个很好的算法点。

标准 TD3 对 performance value 使用：

\[
\min(Q_1,Q_2)
\]

原因是避免：

> 对收益过于乐观。

你的安全问题正好相反。

最危险的是：

> 对风险过于乐观，也就是低估风险。

所以定义：

\[
\boxed{
Q_R^{\mathrm{cons}}
=
\min
(Q_{R,1},Q_{R,2})
}
\]

而 Safety Critic：

\[
\boxed{
Q_C^{\mathrm{cons}}
=
\max
(Q_{C,1},Q_{C,2})
}
\]

形成一个非常漂亮的**非对称保守估计机制**：

\[
\boxed{
\text{Reward：取较悲观收益}
}
\]

\[
\boxed{
\text{Safety：取较悲观风险}
}
\]

这个点我认为完全可以成为算法章节里的核心创新之一。

---

# 十五、Reward Critic 的 TD target

标准 TD3 的思想保留。

+\epsilon,

\right]
\]

其中：

\[

\sim
\operatorname{clip}
(

)
\]

然后：

\[
\boxed{

=

+

\min_{i=1,2}
Q_{R,i}'
(
H_{t+1},
\tilde a_{t+1}
)
}
\]

其中 \(H_t\) 表示 CfC 编码得到的历史状态。

(

\]

两个 Safety Critic：

分别逼近这个 target。

我认为这是你整篇文章算法部分最值得重点写的公式之一。

# 十八、\(\beta\) 不手工固定，而是自适应 Lagrange Multiplier

避免再手调：

\[

\[

\]

\[

然后：

则：

\[

\]

如果长期非常安全：

\[

\]

则：

\[

# 二十二、Rate Limiter 改成“非对称”的

原来：

\[

\le

\boxed{

\[

\[

\end{cases}
