# 原始材料说明

本目录中的两份 `.txt` 是用户提供附件的逐字节副本，用于追溯研究思路，不代表已经通过工程或文献核验。

正式实现与论文写作以同级的 `method_blueprint.md`、`experiment_roadmap.md` 和 `decision_log.md` 为准。整理过程中已经修正/澄清了原文中两个容易出错的接口：

- elevator 剩余余度方向必须结合 \(C_{m_{\delta_e}}\) 的符号；
- \(\eta_C\) 的分子使用相对当前舵面力矩的增量需求，不能把总力矩需求与剩余增量能力混用。

原文涉及的最新文献、发布日期和创新性判断仍需独立检索后才能写入论文。
